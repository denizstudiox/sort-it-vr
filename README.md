# Sort It! VR

Sort It adlı VR oyunu için hazırlanmış animasyonlu, responsive tanıtım sitesi.

## Yerel geliştirme

```bash
npm install
npm run dev
```

## GitHub Pages çıktısı

```bash
GITHUB_PAGES=true SITE_URL=https://denizstudiox.github.io/sort-it-vr/ npx next build
```

Statik çıktı `out/` klasöründe oluşturulur.
